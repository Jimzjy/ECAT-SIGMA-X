# ECAT_SIGMA-X 伺服驱动器手持配置器

一个基于 **STM32F103C8T6 + W5500** 的手持式 EtherCAT 配置工具，用于对安川 **SIGMA-X 系列**（EtherCAT 通讯版）伺服驱动器及其衍生机型进行**参数查看/修改、参数批量写入、编码器复位和参数初始化**，通过 OLED 屏和 5 个物理按键离线操作，不依赖电脑。

## 为什么需要它

SIGMA-X 系列驱动器没有实体操作面板，原厂只能通过电脑软件 **SigmaWin** 用 miniUSB 线连接调试。实际使用中有两个痛点：

- 甲方现场人员操作 SigmaWin 难度较高；
- SigmaWin 自带的 USB 驱动存在签名校验问题，需要关闭系统强制驱动签名才能使用，非常麻烦。

本工具走 **EtherCAT 网口**直接与驱动器通讯（网口即插即用，无需装驱动），把常用的配置操作固化成手持设备上的菜单，现场一键完成。

## 功能

主菜单共 5 项：

| 菜单项 | 功能 |
|---|---|
| 重新连接 | 扫描 EtherCAT 网络，重新建立与驱动器的连接 |
| 参数查看/修改 | 逐个读取驱动器参数，可直接修改并写回 |
| 参数批量写入 | 把内置的整机参数预设一键写入驱动器（含 CNCMC800-X / CNCMC800-Y / JH800-Y 三套预设，预设值在 `Core/Src/ecat_params.c` 中维护） |
| 编码器复位 | 对绝对值编码器执行复位流程（参数 `0x2710` 的写入/读取时序） |
| 参数初始化 | 将驱动器恢复出厂参数 |

支持的机型：**CNCMC800-X、CNCMC800-Y、JH800-Y**（均基于 SIGMA-X EtherCAT 版驱动器）。新增机型只需在 `ecat_params.c` 里增加一组 `ImportParameter` 预设。

## 硬件

- 主控：STM32F103C8T6
- 网口：W5500（MACRAW 模式收发原始以太网帧，自实现精简 EtherCAT 主站，未用 SOEM 等协议栈）
- 显示：0.96" OLED（I2C1）
- 按键 ×5：确认 / 返回 / 上下 / 取消
- 结构与电路设计文件在 `model/`（SolidWorks 结构件）和 `eda/`（立创 EDA 工程ECAT-Y-V1）

### 接线

W5500 ↔ STM32：

| W5500 引脚 | STM32 引脚 |
|-----------|-----------|
| SCLK | PB13 (SPI2) |
| MISO | PB14 |
| MOSI | PB15 |
| SCS | PB12 |
| INT | PA11 |
| RST | PA12 |

按键 ↔ STM32：

| 按键 | STM32 引脚 |
|------|-----------|
| 确认 | PA5 |
| 选择 | PA6 |
| 下 | PA7 |
| 上 | PB0 |
| 返回 | PB1 |

驱动器通过标准网线接到 W5500 的 RJ45 口。

## 使用步骤

1. 用网线把手持设备与驱动器 EtherCAT 口连接，驱动器上电，然后给手持设备上电。
2. 设备启动后自动扫描网络并连接第一台从站；如失败可从主菜单选「重新连接」。
3. 按菜单操作：
   - **参数查看/修改**：上下键选参数编号 → 确认读取 → 上下键改数值 → 确认写入；
   - **参数批量写入**：选机型预设 → 确认 → 等待逐条写入完成；
   - **编码器复位**：确认后按提示执行，期间不要断电；
   - **参数初始化**：确认后执行出厂参数恢复。
4. 「返回」键回到上一级菜单。

> ⚠️ 修改驱动器参数影响设备运行行为，请确认参数含义后再写入；编码器复位与参数初始化会让原位置数据丢失，请在安全状态下操作。

## 编译与烧录

需要 `arm-none-eabi-gcc` 工具链与 CMake：

```bash
cmake --preset Debug        # 或 Release
cmake --build build/Debug
```

产物为 `build/Debug/ECAT_M.hex`（或 `Release`），用 ST-Link 等工具烧录到 STM32F103C8T6。

## 项目结构

```
ECAT_SIGMAX/
├── Core/                    # STM32CubeMX 生成的核心代码 + 业务逻辑
│   ├── Src/main.c           # 界面与菜单流程、编码器复位/初始化流程
│   ├── Src/ecat_params.c    # 各机型参数预设与参数规则表
│   └── ...
├── HW/                      # 硬件驱动
│   ├── ecat/                # 精简 EtherCAT 主站（SDO 读写、状态机）
│   ├── w5500/               # W5500 MACRAW 网卡驱动
│   └── oled/                # OLED 显示驱动与字库
├── SOEM-2.0.0/              # 参考用的 SOEM 源码（当前固件未链接）
├── eda/                     # 立创 EDA 电路工程
├── model/                   # SolidWorks 结构件模型
├── ECAT_M.ioc               # STM32CubeMX 工程文件
└── CMakeLists.txt           # CMake 构建
```
